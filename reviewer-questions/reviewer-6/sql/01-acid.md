- ACID ensures database transactions are safe and reliable.
- A = Atomicity, C = Consistency, I = Isolation, D = Durability.

- Atomicity → A transaction is fully completed or fully rolled back. No partial changes.
- Consistency → Data always stays valid and follows database rules.
- Isolation → Multiple transactions run independently without affecting each other.
- Durability → Once data is committed, it is permanently saved even after a crash.
