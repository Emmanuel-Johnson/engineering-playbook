- Binary Search Tree (BST) is used for fast searching, insertion, and deletion of data.
- It is commonly used in databases, file systems, and indexing systems.
- BST keeps data in sorted order, making range queries and retrieval efficient.

Average time complexity of BST operations:

- Search → O(log n)
- Insertion → O(log n)
- Deletion → O(log n)

Worst case (unbalanced BST) → O(n).
