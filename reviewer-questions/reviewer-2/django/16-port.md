- A port is a logical number used to identify a specific service or application on a computer network.
- It helps data reach the correct program, like HTTP uses port 80 and HTTPS uses port 443.


It means many programs use the internet at the same time on one computer.

For example:

Chrome browser
WhatsApp
MySQL database

All receive data from the network.
The port number tells the operating system which exact program should get that data.
