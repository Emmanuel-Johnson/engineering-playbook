Depth of a node — Number of edges from the root node to that node.

Height of a node — Number of edges in the longest path from that node to a leaf node.

Height of a tree — Longest path from root to deepest leaf node.

Level of a node — Position of a node based on distance from the root.

Degree of a node — Number of children a node has.

Degree of a tree — Maximum degree of any node in the tree.

Leaf node — A node with no children.

Internal node — A node with at least one child.

Root node — Topmost node of a tree.

Parent node — A node that has child nodes.

Child node — A node directly connected below a parent.

Sibling nodes — Nodes having the same parent.

Subtree — A smaller tree formed from a node and its descendants.

Ancestor node — Any node on the path from root to a given node.

Descendant node — Any node below a given node.

Binary tree — A tree where each node has at most 2 children.

Full binary tree — Every node has either 0 or 2 children.

Complete binary tree — All levels are full except possibly the last, filled left to right.

Perfect binary tree — All internal nodes have 2 children and all leaf nodes are at the same level.

Balanced binary tree — Height difference between left and right subtree is minimal.

Skewed tree — A tree where nodes form a linear structure.

Binary Search Tree (BST) — Left subtree values are smaller and right subtree values are greater than root.

Tree traversal — Method of visiting all nodes in a tree.

Preorder traversal — Root → Left → Right.

Inorder traversal — Left → Root → Right.

Postorder traversal — Left → Right → Root.

Level order traversal — Visiting nodes level by level using a queue.

Time complexity of traversal — O(n), because every node is visited once.

Space complexity of DFS — O(h), where h is the height of the tree.

Space complexity of BFS — O(n), due to queue storage.
