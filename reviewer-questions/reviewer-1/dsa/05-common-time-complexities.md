- Common time complexities are: O(1), O(log n), O(n), O(n log n), O(n²), and O(2ⁿ).
- They describe how execution time grows as input size increases.
- O(1) is fastest, while exponential complexities like O(2ⁿ) are the slowest.

Common time complexities:

- O(1) → Constant time
- O(log n) → Logarithmic time
- O(n) → Linear time
- O(n log n) → Linearithmic time
- O(n²) → Quadratic time
- O(2ⁿ) → Exponential time
- O(n!) → Factorial time
